Your PDF library in the browser

A private page for the papers in a Dropbox folder: browse by author, journal and topic, search titles and abstracts, open PDFs in the Dropbox viewer, keep notes, and upload new papers from your phone.

Open the library Set up the full version

How it works

  • The page runs entirely in your browser. You log in with your own Dropbox; nothing about your library is stored on this website.
  • You choose one Dropbox folder as your library (folder icon in the header, changeable any time).
  • Without anything else, the page lists the PDFs in that folder by file name and date, with search, the Dropbox viewer, and uploads.
  • With an index (a file index.json in the same folder, built by Claude Code with the lit skill), you also get authors, journals, topics (JEL codes), abstracts, versions and appendices, your notes, and a to-download list.

Step 1: use the page (2 minutes, no installation)

  1. Open the library page and press Connect Dropbox. Dropbox asks you to allow access; confirm.
  2. Pick the folder with your PDFs and press Use this folder.
  3. That's it. Bookmark the page or add it to your phone's home screen.
If Dropbox refuses the login (“app not available” or similar): the Dropbox app behind the page is still in development mode and needs to be opened for more users. Tell Jeremias.

Step 2: the full version with Claude Code (once)

For authors, journals, topics and abstracts, Claude reads your PDFs once and writes the index. You need a Mac (or Linux) with the Dropbox desktop app syncing your library folder, and Claude Code.

Paste this into Claude Code

Open Terminal, type claude, and paste the message below. Claude downloads the skill from this site, installs what it needs, asks you for your library folder, and builds the index. Claude asks before running commands; for a few hundred PDFs the index takes a while.

Please install the "lit" library skill from https://jklaeui.github.io/library/ and build the index of my PDF library.

1. Create ~/.claude/skills/lit/ and download these files into it with curl, saving SKILL.txt as SKILL.md:
   https://jklaeui.github.io/library/skill/SKILL.txt
   https://jklaeui.github.io/library/skill/lit.py
   https://jklaeui.github.io/library/skill/library.py
   https://jklaeui.github.io/library/skill/jel.json
   https://jklaeui.github.io/library/skill/jel_short.json
   Skim the two Python scripts and tell me in two sentences what they do before running anything.
2. Check that pdftotext works (otherwise: brew install poppler) and that Python has requests, beautifulsoup4 and lxml (otherwise: python3 -m pip install --user requests beautifulsoup4 lxml).
3. Find my Dropbox folder on this computer (~/.dropbox/info.json, ~/Library/CloudStorage/Dropbox*, ~/Dropbox) and ask me which folder in it holds my PDFs. Then run:
   python3 ~/.claude/skills/lit/library.py setup --folder "<that folder>"
4. Ask me whether I have a free OpenAlex API key (openalex.org/settings/api). If yes, save it to ~/.config/openalex/api_key.
5. Build the index as described in ~/.claude/skills/lit/SKILL.md under "First time": sync, verify, review flagged papers, JEL codes. Keep me posted while it runs.
6. When done, tell me how many papers are in the index and which folder to pick on https://jklaeui.github.io/library/ (folder icon).

Afterwards, reload the library page. If you picked a different folder there before, choose the one Claude names (folder icon).

Prefer to do it by hand?
  1. Download the five files from https://jklaeui.github.io/library/skill/ (SKILL.txt, lit.py, library.py, jel.json, jel_short.json) into ~/.claude/skills/lit/ and rename SKILL.txt to SKILL.md.
  2. brew install poppler and python3 -m pip install --user requests beautifulsoup4 lxml
  3. Optional free OpenAlex key from openalex.org/settings/api, saved in ~/.config/openalex/api_key.
  4. python3 ~/.claude/skills/lit/library.py setup --folder "<your PDF folder inside Dropbox>"
  5. In Claude Code: /lit build the index of my library

Adding papers later

  1. On the page, press the upload icon and pick PDFs (works on the phone). They appear under Uploads by file name.
  2. Back at the Mac, in Claude Code: /lit update the library. The papers move into the library with full details.

Shortcut: save this as Update Library.command on your Desktop, make it executable (chmod +x), and double-click it:

#!/bin/zsh
cd ~ && claude "/lit Update the library: run library.py inbox, then sync, verify, assign JEL codes to new papers, and handle anything flagged."

The download icon shows a to-download list (papers you want but have no PDF for). Ask Claude to add entries, e.g. /lit put "Title" by Author on my to-download list.

Privacy

  • Your Dropbox login stays in your browser. Log out on the page removes it; you can also disconnect the app in Dropbox under Settings → Connected apps.
  • Dropbox only offers this kind of app access to the whole Dropbox, not to a single folder. The page reads only the folder you choose and writes only uploads into its _inbox subfolder.
  • Do not log in on shared computers.
