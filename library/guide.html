Your PDF library in the browser

A private page for the papers in a Dropbox folder: browse by author, journal and topic, search titles and abstracts, open PDFs in the Dropbox viewer, keep notes, and upload new papers from your phone.

Open the library Download the Claude skill (lit-skill.zip)

How it works

  • The page runs entirely in your browser. You log in with your own Dropbox; nothing about your library is stored on this website.
  • You choose one Dropbox folder as your library (folder icon in the header, changeable any time).
  • Without anything else, the page lists the PDFs in that folder by file name and date, with search, the Dropbox viewer, and uploads.
  • With an index (a file index.json in the same folder, built by Claude Code with the lit skill), you also get authors, journals, topics (JEL codes), abstracts, versions and appendices, your notes, and a to-download list.

Step 1: use the page (2 minutes, no installation)

  1. Open the library page and press Connect Dropbox. Dropbox asks you to allow access; confirm.
  2. Pick the folder with your PDFs and press Use this folder.
  3. That's it. Bookmark the page or add it to your phone's home screen.
If Dropbox refuses the login (“app not available” or similar): the Dropbox app behind the page is still in development mode and needs to be opened for more users. Tell Jeremias.

Step 2: the full version with Claude Code (once, about 15 minutes)

For authors, journals, topics and abstracts, Claude reads your PDFs once and writes the index. You need a Mac (or Linux) with the Dropbox desktop app syncing your library folder, and Claude Code.

2.1 Install the skill

  1. Download lit-skill.zip and unzip it into ~/.claude/skills/, so that you get ~/.claude/skills/lit/SKILL.md.
  2. Install the tools it uses, in Terminal: 
    brew install poppler
python3 -m pip install requests beautifulsoup4 lxml
  3. Optional but recommended: get a free OpenAlex key at openalex.org/settings/api (raises the daily limit from about 100 to about 1,000 lookups) and save it: 
    mkdir -p ~/.config/openalex
echo "YOUR_KEY" > ~/.config/openalex/api_key

2.2 Point it at your folder

python3 ~/.claude/skills/lit/library.py setup --folder "~/Dropbox/Papers"

Use the path of your library folder on your Mac (in Finder: right-click the folder, hold Option, “Copy … as Pathname”). The command prints the folder as the web page sees it; it must match the folder you picked there.

2.3 Build the index

Start Claude Code in any folder and type:

/lit build the index of my library

Claude reads every PDF (DOI, title, authors, abstract, JEL codes), looks papers up on OpenAlex, groups versions of the same paper, and asks or fixes what it cannot identify. For a few hundred PDFs this takes a while; you can watch it work. Then reload the library page.

Adding papers later

  1. On the page, press the upload icon and pick PDFs (works on the phone). They appear under Uploads by file name.
  2. Back at the Mac, in Claude Code: /lit update the library. The papers move into the library with full details.

Shortcut: save this as Update Library.command on your Desktop, make it executable (chmod +x), and double-click it:

#!/bin/zsh
cd ~ && claude "/lit Update the library: run library.py inbox, then sync, verify, assign JEL codes to new papers, and handle anything flagged."

The download icon shows a to-download list (papers you want but have no PDF for). Ask Claude to add entries, e.g. /lit put "Title" by Author on my to-download list.

Privacy

  • Your Dropbox login stays in your browser. Log out on the page removes it; you can also disconnect the app in Dropbox under Settings → Connected apps.
  • Dropbox only offers this kind of app access to the whole Dropbox, not to a single folder. The page reads only the folder you choose and writes only uploads into its _inbox subfolder.
  • Do not log in on shared computers.
